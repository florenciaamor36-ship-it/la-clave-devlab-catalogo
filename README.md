# La Clave DevLab — Catálogo Build Your Own X

Catálogo web en español para explorar guías públicas de aprendizaje sobre cómo recrear tecnologías desde cero. El proyecto web, la edición, la organización y la presentación son de **La Clave Argentina**.

## Qué contiene

- `index.html`, `styles.css`, `app.js`: sitio estático responsivo con búsqueda, filtros por categoría y lenguaje, filtro de videos, orden y enlaces a fuentes.
- `catalog.json`: índice de tutoriales extraído del README público de Build Your Own X. Los enlaces llevan a los sitios originales de cada autor.

## Ejecutar localmente

Como el catálogo se carga con `fetch`, servir la carpeta con un servidor estático local (por ejemplo, `python -m http.server 8000`) y abrir `http://localhost:8000`.
